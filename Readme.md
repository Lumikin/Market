# 📚 Projeto Loja

Bem-vindo à **Loja**.
Este repositório contém a documentação e implementação de um sistema de loja virtual desenvolvido pela equipe Rotina+.

## 🎯 Objetivo

Projeto acadêmico com o objetivo de apoiar o ensino de **back-end e front-end**, abordando conceitos como:

- Arquitetura de sistemas
- Modelagem de dados (DER)
- Programação orientada a objetos
- Desenvolvimento de interfaces
- Boas práticas de organização de código
